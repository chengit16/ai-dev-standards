## 许可证建议

建议对有权授权的工具包源码、文档、规则、Skills 和空白工程模板使用 MIT。MIT 允许使用、修改、分发和商用，要求在分发副本或实质部分时保留版权及许可声明。如果需要明确的贡献者专利授权条款，可选择 Apache-2.0。版权声明使用权利人确认的名称。[MIT 许可文本](https://opensource.org/license/mit) · [Apache-2.0 许可文本](https://www.apache.org/licenses/LICENSE-2.0)

正式版本在仓库根目录保留 `LICENSE`，如有适用的第三方声明则随附 `NOTICE`。发行包与安装副本携带这些声明。依赖由模板的包管理器按锁文件安装，各依赖沿用自身许可。
