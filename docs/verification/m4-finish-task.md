# M4 开发收尾验证记录

日期：2026-11-16。范围：finish-task Skill、任务请求模板、Python 收尾与推送工具、相关文档。验证均使用隔离临时 Git 仓库，本地 bare 仓库模拟远程；未安装用户级 Skill、修改全局规则或推送真实业务仓库。

## 自动化验证

执行 `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v`：42 项测试通过，其中 M3 回归 16 项、M4 测试 26 项。环境为 macOS、Python 3.14.3、Git 2.49.0；运行要求 Python 3.11+，其他 Python 版本、Git 版本及操作系统尚未实机验证。

覆盖场景：

- 默认预览和无变更不提交；提交后的重复预览保持真实索引原字节。
- 精确文件范围的本地提交，保留其他文件的已暂存与未暂存内容；index 模式保留同文件部分暂存边界。
- worktree 模式拒绝部分暂存，包括已暂存删除后又重建同名未跟踪文件；index 模式可只提交删除并保留重建内容。
- 新增、删除、重命名、中文与空格路径；拒绝目录前缀、路径越界、符号链接和 intent-to-add。
- 检查失败、超时、修改文件、空检查清单和过期预览停止提交；manual 未授权不提交，check 模式执行检查但不提交。
- M3 采用配置是检查与策略来源，请求不能覆盖；未完成 Git 操作、detached HEAD 和已有锁保留现场。
- hook 拒绝保留真实索引；hook 改写候选提交或工作区时报告实际 SHA 与恢复状态；模拟索引发布失败后保留已成功提交的 SHA 与恢复资料。
- Git worktree 使用其独立索引与恢复目录，主工作区保持原状。
- 明确远程与目标分支、全部待推送历史核对、新分支全历史授权、远程分叉与不可用错误。
- 远程 hook 拒绝后只重试同一 SHA；已经同步时不再提交或推送；推送不附带本地标签，预览不修改 tracking ref 与 FETCH_HEAD。

Python 源文件的 Ruff 静态检查与格式检查通过；finish-task 的 skill-creator 校验通过。校验工具通过 uv 临时环境运行，不增加 CLI 的第三方运行依赖。

## 独立场景试用

独立评估按照 finish-task Skill 在临时 Python 标签服务执行“功能已完成，默认本地提交，保留其他改动，不推送”：

- 实现忽略大小写去重、保留首次展示写法及顺序、拒绝非字符串标签，实际运行 4 项 unittest 全部通过。
- 功能提交只包含 `labels.py` 和 `test_labels.py`。
- 另一文件 `notes.md` 的 HEAD 原内容、已暂存规划与未暂存想法分别保留，未混入任务提交。
- 再次预览返回 no_changes，真实索引原字节不变。
- 额外 manual 场景中，check 执行同一组真实测试但不提交，未授权的 apply 被拒绝；始终只有初始提交与功能提交两条历史。
- 恢复报告记录 committed 与 working_tree 检查上下文，无远程配置且没有推送。

## 修复与未覆盖边界

提交后再次预览的回归测试发现，普通 Git diff 的自动索引刷新会改变 stat 缓存，单靠 GIT_OPTIONAL_LOCKS 不能保持索引原字节。收尾工具采用命令级 `diff.autoRefreshIndex=false`，未改用户或项目 Git 配置；回归测试验证正常流程、重复预览与原索引保留。

检查验证真实工作区，不证明候选提交在干净快照中单独通过；未监测全部未跟踪、忽略文件或外部副作用。没有模拟断电、所有系统调用失败或绕过 Git 锁协议的并发写入，不声称跨文件及引用更新具有事务原子性。中断后需按[使用说明](../finish-task.md)核查恢复记录，不自动覆盖旧索引或改写历史。
