# 版本与兼容

工具包计划通过 Git 标签发布版本，当前尚未发布正式版本。规范源文件保留参考项目及其固定提交，避免来源漂移。

M3 生成的 `manifest.json` 使用 `schema_version: 1`，记录工具包 Git 提交、相关工作树状态，以及所采用规范和入口模板的 SHA-256 内容集合指纹。来自未提交工作树的生成物是可校验的内容快照，不等同于该 Git 提交的完整发布版本。

业务项目通过 `project.json` 保存选择、检查与差异。重复初始化只允许内容一致，工具包升级不会自动修改既有项目。受管内容、配置或来源变化时停止覆盖；显式规范升级与三方合并留待后续实现。
