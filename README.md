# AI 开发规范工具包

将个人开发规范、前后端技术栈约定与 AI 开发工作流集中维护，通过 Git 分发到不同电脑，在具体项目中生成可持续维护的工程规则。

## 当前状态

已提供通用、React 前端及两套后端规范，实现 M3 项目初始化和 M4 开发收尾。完整工具包副本可生成项目规范、执行检查并按策略本地提交，推送作为单独授权的步骤。M2 已提供安装、更新、诊断、卸载与恢复入口，并通过隔离验证；真实本机加载与跨电脑验收仍待用户执行。

第一版面向 Codex。其他 AI 开发工具的适配属于后续范围。

已将可复用的空白工程模板及“创建工程 → 接入规范 → 验证”流程纳入 M5 规划，尚未实现。工具包维护通用模板，生成的业务项目保存在各自独立目录和仓库。

## 目标体验

1. 新电脑克隆本仓库，运行安装程序，启用个人规则与 Skills。
2. 新项目确定技术栈后，从空白模板创建基础工程、接入适用规范并运行实际检查；已有项目可只接入规范。空白工程创建与串联验证为 M5 待实现能力。
3. 每完成一个可独立验收的开发任务，执行必要检查并按策略提交。
4. 更新工具包时保留本机配置；更新业务项目规范时查看差异并合并。

用户级生命周期、项目规范初始化和任务收尾已有源码入口；空白工程创建、统一验证、便捷命令分发、已有业务项目的规范升级及正式发布仍属后续范围。

## 默认策略

- 文档和新增注释使用中文，技术标识符保持原样。
- 开发任务完成并通过必要检查后，默认自动本地提交；推送需要单独启用。
- 全局规则保留既有内容，安装器仅管理带有本工具包标记的区块。
- 业务项目记录规范版本，工具包升级不自动改写已有业务项目。
- 本机绝对路径等配置与可共享规范分离。
